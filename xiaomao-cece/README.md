# 小猫测测

1.0.2 H5 浏览器预览，用于手机体验及截图、录屏采集。

- 入口：`index.html`。游戏文件来自已确认的1.0.2包，题库、计分、页面与存档规则保持一致。
- 手机浏览器首次进入赠送1条小鱼干，可完成一次娱乐测试并解锁结果。浏览器存档与TapTap各自保存。
- TapTap激励视频依赖TapTap宿主；普通浏览器会提示在TapTap内打开，不提供模拟广告奖励。
- GitHub Pages发布来源：main分支根目录。`.nojekyll`用于直接提供静态文件。

发布设置参考：[GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
